# Atividade: Tipos em TypeScript

Arquivos ex01.ts até ex10.ts com exemplos e comentários simples. As linhas que provocam erros ficam comentadas para manter a compilação.

## Compilar e executar

No terminal aberto nesta pasta:

```text
npx --yes --package typescript tsc --strict --ignoreConfig ex01.ts
node ex01.js
```

Para compilar tudo de acordo com tsconfig.json:

```text
npx --yes --package typescript tsc --project tsconfig.json
```

Troque ex01 pelo exercício que deseja executar.
